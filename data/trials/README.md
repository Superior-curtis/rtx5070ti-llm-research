# Allowlisted historical per-trial metrics

These six JSONL files are derived directly from the laboratory's historical JSONL files (not generated by the new reference harness). Each record preserves the original numeric precision and boolean/null values for selected measurement fields. `source_row` is a one-based line number in the source file. Free text, questions, answers, expected answers, logs containing paths, model output previews and unknown string fields were excluded. Known categorical values (reasoning effort and termination status) were retained. These are sanitized metric extracts, **not untouched raw logs**.

Field names follow the original logs: `promptTokens`, `completionTokens` / `outputTokens` / `tokens`, `serverDecode` / `serverTokS` / `tg` / `tokS` (decode rate), `serverPrefill` / `pp` (prefill rate), `ttftSec`, `totalSec` / `elapsedSec` / `sec` / `wallSec`. Client stream rates are separate. Missing fields are unrecorded or not in the release allowlist; never treat them as zero. Strata marker counts were computed only from boolean marker scores; the NInfer `correct` field is a marker count, whereas Swift `correct` is a boolean.

The extracts do not include all historical experiments, individual public benchmark items or full source logs. Exact prompts, model outputs and per-item identifiers are withheld, so these files permit aggregate auditing but not independent rescoring of every response. See [methodology](../../METHODOLOGY.md).
